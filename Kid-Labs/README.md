# Kid Labs (Kid_Labs)

### A Sustainability Learning & Carbon Awareness Platform

Kid-Labs is designed to promote sustainability awareness, carbon literacy, and climate-conscious behaviour through interactive quizzes, learning experiences, and analytics.

Designed to support multiple audience categories across kids and young adults.

## Platform Categories

| Category | Target Audience |
|---|---|
| Individual | Adults aged 21+ |
| Young Adults | Individuals aged 15–20 |
| Kids | Children aged 8–14 |
| School Students | Junior and Senior School Students |
| College Students | Undergraduate and postgraduate students |

## Key Features

- Age-appropriate sustainability quizzes.
- Interactive learning experiences and challenges.
- Carbon footprint awareness and education.
- Green points and engagement tracking.
- Category-specific dashboards and analytics.
- Sustainability awareness for educational institutions.
- Potential future expansion into employee and corporate sustainability programmes.

## Technology Stack

- **Frontend:** Web application hosted through Netlify.
- **Backend:** Google Apps Script.
- **Database:** Google Sheets.
- **Version Control:** GitHub ([https://github.com/thegreenerquest/Kid_Labs](https://github.com/thegreenerquest/Kid_Labs)).
- **Domain:** Custom subdomain for Kid-Labs.

## Architecture

Kid-Labs operates independently as a dedicated platform:

- Separate GitHub repository (`thegreenerquest/Kid_Labs`).
- Independent frontend deployment.
- Dedicated Google Apps Script project and deployment.
- Separate Google Spreadsheet as its backend.
- Independent application configuration.
